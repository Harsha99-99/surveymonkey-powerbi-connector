        Scheduled refresh from this PC
        
        
        Power BI's cloud service can't reach this PC by itself. Microsoft's free on-premises data gateway, running here, fetches the data for it. So at refresh times this PC must be on, awake and signed in to Windows, with the connector running.
        

        
          
          
        1. 
            Keep the connector running. It only syncs from SurveyMonkey, on its schedule, while it's running.
            
            
          
            
          
          
          2. 
          
        2. 
            Stop the PC sleeping at refresh times. In Windows Settings → System → Power, set the PC to never sleep while plugged in, or at least not around your refresh times.
          
          3. 
          
        3. 
            Install the gateway in personal mode. Download it, run the installer, choose On-premises data gateway (personal mode), and sign in with the account you use for Power BI. It doesn't need administrator rights. Each person can run only one personal gateway.
            
          
          
          4. 
          
        4. 
            Publish your report. In Power BI Desktop, choose Home → Publish and pick a workspace.
          
          5. 
          
        5. 
            Connect the semantic model to the gateway. In the Power BI service, open the workspace, find the semantic model, and open its Settings. Under Gateway and cloud connections, choose your personal gateway. It shows as online while it's running.
            
          
          
          6. 
          
        6. 
            Set the data source credentials. Under Data source credentials, edit the credentials for http://localhost:7071: choose Anonymous, privacy level Organizational, and tick Skip test connection. The queries from this app keep the address fixed, which is what lets the service refresh them.
          
          7. 
          
        7. 
            Turn on scheduled refresh. Under Refresh, turn on the refresh schedule, choose your time zone and add times.  Power BI Pro allows up to 8 refreshes a day; Premium Per User and Premium capacity allow 48.
          
          8. 
          
        8. 
            Test it. Choose Refresh now on the semantic model and check its refresh history. After four failed refreshes in a row, Power BI turns the schedule off, so check back after the first scheduled one.
          
          9. 
        
        
      
        

      
        
        
        Scheduled refresh from Azure (later)
        
        
        Once the connector is deployed to Azure, Power BI refreshes from it directly. No gateway, and no PC has to stay on.
        
        
          
          
        1. Deploy the connector with the Deploy to Azure button in the README, and finish its setup wizard.
          2. 
          
        2. Use your Function App's address in place of http://localhost:7071 in the queries, and add the function key header, as shown in docs/powerbi.md.
          3. 
          
        3. In the semantic model's Data source credentials, choose Anonymous and tick Skip test connection. The key travels in the header.
          4. 
          
        4. Set refresh times. On Azure the connector's schedule is always in UTC, so convert to your time zone when you line up refreshes after syncs. Don't set WEBSITE_TIME_ZONE or TZ: the plan this project deploys doesn't support them, and setting them causes errors.
